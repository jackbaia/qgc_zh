# QGroundControl 中文术语表

本术语表用于 QGC 中文界面、参数说明、飞控状态消息、日志分析结果等文案校对。原则是保留 PX4、MAVLink、EKF、RTK、ULog 等专有名词，在中文里补足飞控语境，避免机械直译。

| English | 推荐中文 | 禁止/不推荐翻译 | 说明 |
| ------- | -------- | ---------------- | ---- |
| Vehicle | 飞行器 / 无人机 / 载具 | 车辆 | QGC 中多数指被控飞行器；无人车/船语境可用载具。 |
| Arm | 解锁 | 手臂、武装 | 指允许电机/执行器进入可工作的解锁状态。 |
| Disarm | 上锁 | 解除武装 | 指退出解锁状态，禁止电机意外输出。 |
| Mission | 任务 / 航线任务 | 使命 | Plan View 中多指航线任务。 |
| Takeoff | 起飞 | 脱离 | 飞行模式和命令统一用起飞。 |
| Land | 降落 | 土地 | 飞行模式和命令统一用降落。 |
| Return | 返航 | 返回 | 飞控语境通常指返回 Home 点。 |
| RTL | RTL 返航 | 返回 | 保留 RTL 缩写并解释为返航。 |
| Loiter | 悬停/盘旋 | 游荡 | 多旋翼常用悬停，固定翼常用盘旋。 |
| Hold | 保持 | 拿住 | 模式语境可写保持/悬停保持。 |
| Failsafe | 失效保护 / 故障保护 | 故障安全 | 表示链路、电池、定位等异常时触发的保护策略。 |
| Estimator | 状态估计器 | 估算器 | EKF/定位相关语境使用状态估计器。 |
| Setpoint | 设定值 / 控制目标 | 设置点 | 控制器语境优先用控制目标。 |
| Attitude | 姿态 | 态度 | 飞行器姿态包含横滚、俯仰、偏航。 |
| Rate | 角速度 / 速率 | 率 | 角速度控制中用角速度；数据传输中用速率。 |
| Yaw | 偏航 | 偏摆 | 姿态/角速度三轴之一。 |
| Pitch | 俯仰 | 音高 | 姿态/角速度三轴之一。 |
| Roll | 横滚 | 滚动 | 姿态/角速度三轴之一。 |
| Throttle | 油门 / 推力输入 | 节流阀 | 遥控输入多用油门，多旋翼控制可用推力输入。 |
| Actuator | 执行器 | 致动器 | 电机、舵机等输出设备。 |
| Compass | 罗盘 / 磁罗盘 | 指南针 | 传感器校准界面多用罗盘。 |
| Magnetometer | 磁力计 | 磁强计 | 传感器名称。 |
| Barometer | 气压计 | 晴雨表 | 高度估计传感器。 |
| Airspeed | 空速 | 空气速度 | 固定翼空速传感器/估计值。 |
| Groundspeed | 地速 | 地面速度 | 对地速度。 |
| Position Mode | 位置模式（定点） | 位置方式 | PX4 多旋翼常见飞行模式。 |
| Altitude Mode | 高度模式（定高） | 海拔模式 | PX4 多旋翼常见飞行模式。 |
| Offboard | Offboard 外部控制 | 离板 | 保留 Offboard，并补充中文解释。 |
| Parameter | 参数 | 参量 | 飞控参数统一用参数。 |
| Calibration | 校准 | 标定（除专业传感器语境） | QGC UI 统一用校准。 |
| Firmware | 固件 | 固件程序（冗余） | PX4/ArduPilot 固件。 |
| Sensor | 传感器 | 感应器 | 硬件传感器统一用传感器。 |
| Frame | 机架 / 坐标系 / 画面帧 | 帧（全局统一） | Airframe 是机架；coordinate frame 是坐标系；video frame 是画面帧。 |
| Telemetry | 遥测 | 数传（仅链路硬件时） | 数据内容用遥测，电台/链路可用数传链路。 |
| Link | 链路 / 连接 | 链接（网页语境除外） | 通信语境用链路。 |
| Fence | 围栏 | 栅栏 | 飞控边界语境用围栏。 |
| Geofence | 地理围栏 / 电子围栏 | 地理栅栏 | QGC 安全边界功能。 |
| Rally Point | 备降点 / 集结点 | 集会点 | 任务安全点，按上下文选用。 |
| Home Position | Home 点 / 返航点 | 家庭位置 | 返航和起飞参考位置。 |
| MAVLink | MAVLink | 微型飞行器链接 | 协议名保留英文。 |
| ULog | ULog | 用户日志 | PX4 日志格式名保留英文。 |
| VTOL | VTOL 垂直起降 | 垂直起降飞机（丢缩写） | 保留缩写便于工程排查。 |
| Fixed Wing | 固定翼 | 固定翅膀 | 飞行器类型。 |
| Multirotor | 多旋翼 | 多转子 | 飞行器类型。 |
